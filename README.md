# なかまボード

**無料で使える、仲間の連絡・共有ボード**

町内会・PTA・サークル・小さな会社など、招待した仲間だけで使う連絡アプリです。
Googleのサービス（Googleスプレッドシート＋Google Apps Script）だけで動くので、サーバー代はかかりません。データは、設置した人のGoogleドライブに保存されます。

提供：[ユーカリデジタル](https://eucalydigital.com/)

---

## できること

| 機能 | 内容 |
| --- | --- |
| 掲示板・お知らせ | 投稿・コメント、画像やPDFの添付（PDFはアプリ内で表示）、既読数、重要なお知らせのメール通知 |
| 予定（カレンダー） | 毎日・毎週・毎月の繰り返し、「この日だけ」の変更 |
| メッセージ | 1対1・グループのトーク、既読表示、画像・PDFの添付（6か月で自動削除） |
| グループ | LINEグループのように自由に作成。グループ専用の掲示板・予定・トーク |
| 共有カード | 図面・画像（ペンで書き込み）／表（Googleスプレッドシート）／リンクをカードとして共有。カードごとに「借りる・返す」（返却期限・使用履歴つき）を使える。備品・鍵・担当エリア・資料の管理に |
| 資料箱 | 棚（分類）ごとに、マニュアル・規程・名簿・フォームなどのリンクやファイルを整理。グループ限定の棚も作れる |
| まとめメール | 未読や返却期限を、1日2回（7時・18時ごろ）メールでお知らせ |
| アプリ設定 | アプリ名・アイコンの変更、使う機能のオン・オフ |

スマホのブラウザで使い、「ホーム画面に追加」するとアプリのように開けます。

## 必要なもの

- Googleアカウント（無料のもので使えます。アプリ専用のアカウントを作るのがおすすめです）
- パソコン（設置作業のときだけ）

## 設置手順

### 1. スプレッドシートとスクリプトを用意する

1. Googleドライブで、新しいスプレッドシートを作る（名前は自由。例：なかまボード）
2. メニューの「拡張機能 → Apps Script」を開く
3. 最初からある `コード.gs` の中身をすべて消し、このリポジトリの `Code.gs` の中身を貼り付ける
4. 左の「ファイル」の横の「＋ → HTML」で `Index`・`Styles`・`App` の3つを作り、それぞれ同じ名前のファイルの中身を貼り付ける（「.html」は自動で付きます）
5. 保存する

### 2. 初期設定（setup）

1. 上部の関数の選択欄で `setup` を選び、「実行」を押す
2. 「承認が必要です」と出たら、自分のアカウントを選び、「詳細 → （プロジェクト名）に移動 → 許可」と進む
3. 実行ログに出る「初期管理者の招待コード」（8文字）を控える

`setup` は、必要なシートの作成、添付ファイル用フォルダの作成、まとめメールの自動送信の設定を行います。

### 3. デプロイ（公開）

1. 右上の「デプロイ → 新しいデプロイ」
2. 種類の選択（歯車）で「ウェブアプリ」を選ぶ
3. 「次のユーザーとして実行」＝「自分」、「アクセスできるユーザー」＝「全員」
4. 「デプロイ」を押し、表示されたURLを控える（これがアプリのURLです）

### 4. 最初の登録

1. アプリのURLを開き、「招待コードで登録」から、手順2のコードで登録する（この人が全体管理者になります）
2. 「メニュー → メンバー管理 → アプリ設定」で、アプリ名・アイコン・使う機能を設定する
3. 「招待コード」タブでコードを発行し、メンバーに送る

## 更新のしかた

1. 新しいファイルの中身に置き換えて保存する
2. 「デプロイ → デプロイを管理 → 鉛筆アイコン（編集） → バージョン：新バージョン → デプロイ」（URLは変わりません）
3. 新しい権限が必要になった場合は、もう一度 `setup` を実行して許可する

新しく必要になったシートや列は、自動で追加されます。

## 役割

| 役割 | できること |
| --- | --- |
| 全体管理者 | 招待コードの発行、メンバー管理、各役割の任命、お知らせの投稿、全体の予定の追加、アプリ設定 |
| カレンダー編集者 | 全体の予定の追加・変更 |
| 共有カード管理者 | カードの登録・編集、貸出対象と返却期限の設定、代理での貸し出し・返却、使用履歴、書き込み・コメントの消去 |
| 資料箱管理者 | 資料箱の棚と資料の追加・整理 |
| グループ責任者 | グループのメンバー管理、機能のオン・オフ、グループ内の投稿の削除 |
| 一般メンバー | 閲覧、掲示板への投稿、グループの作成、メッセージ、カードを借りる・返す |

グループの中身（投稿・予定・トーク）は、そのグループのメンバーだけが見られます（全体管理者でも、メンバーでなければアプリ上では見られません）。

## データの保存場所とプライバシー

- スプレッドシート：メンバー、投稿、予定、メッセージなど
- Googleドライブの「（アプリ名）_添付ファイル」フォルダ：添付された画像・PDF（非公開のまま、アプリ経由でのみ表示）
- アイコン画像だけは、ホーム画面のアイコンに使うため「リンクを知っている人は閲覧可」で保存されます

**ご注意**：設置したGoogleアカウントの持ち主は、スプレッドシートやドライブを直接開けば、メッセージを含むすべての内容を見ることができます。運営する人を信頼できる人に限り、メンバーにもそのことを伝えたうえでお使いください。設置用のGoogleアカウントは2段階認証にしてください。

シートや添付フォルダは、直接編集したり共有設定を変えたりしないでください。定期的に「ファイル → コピーを作成」でスプレッドシートの控えを取っておくと安心です。

## 無料のGoogleアカウントでの制限

- メールの送信は1日約100通（宛先数）まで（まとめメールは上限が近いとき、返却が必要な人・未読の多い人を優先します）
- 同時に処理できるのは30件まで。目安として100人程度までのグループ向けです
- アプリの上部に「Google Apps Scriptのユーザーによって作成されたもの」という表示が出ます（Googleの仕様で、消せません）
- iPhoneでは、ホーム画面のアイコンにアプリのアイコンが反映されないことがあります
- 最初に開くときは数秒かかります

## セキュリティ

- パスワードはハッシュ化して保存（元のパスワードは保存しない）
- ログインに続けて5回失敗すると10分間ロック
- すべての操作で、サーバー側がログイン状態と権限を確認
- 入力内容は表示時にエスケープし、スプレッドシートには文字列として保存（数式として実行されない）
